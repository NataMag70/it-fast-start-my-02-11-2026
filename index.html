Main commands git

  • git clone - Команда, яка завантажує репозиторій разом із усією його історією змін.
  • git add - Команда, яка індексує вказаний файл для наступного коміту.
  • git commit -m ""- Команда, яка фіксує проіндексовані зміни й зберігає їх у історії версій.
  • git status - Команда, яка перераховує всі нові або змінені файли, які потребують фіксації.
  • git log - Команда, яка показує історію комітів.
  • git branch - Команда, яка показує список іменованих гілок комітів із зазначенням вибраної гілки.
  • git checkout -b <нова гілка> - Команда, яка створює й переключається на нову гілку.
  • git merge - Команда, яка об'єднує зміни з іншої гілки.
  • git pull - Команда, яка завантажує зміни з віддаленого репозиторію і об'єднує їх з поточною гілкою.
  • git push - Команда, яка завантажує локальні зміни в віддалений репозиторій.
